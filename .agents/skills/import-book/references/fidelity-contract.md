# 충실도 계약

이 파일을 본문 변환 방식의 단일 진실 공급원으로 사용한다. 각 축에서 호출자가 값을 지정하지 않은 경우에만 그 축을 한 번 묻고, 선택 결과를 전체 작업에 그대로 적용한다.

## 본문 모드

### 원문 보존

- 원래 언어와 모든 문장·주장·예시·인용·수치·코드·이미지·캡션·각주를 유지한다.
- 문장 순서를 유지하고 PDF 페이지 경계 때문에 끊긴 문단만 합친다.
- OCR 오자와 잘못된 줄바꿈은 PDF를 근거로 복원한다.
- 원문 추적표에서 모든 원문 블록을 결과 블록에 일대일로 연결한다.

### 완전 번역

- 모든 산문·heading·캡션을 한국어로 옮기고 원문 블록 순서와 개수를 유지한다.
- 코드, 식별자, 명령어, URL, 수식, 고유명사와 직접 인용의 보호 범위를 유지한다.
- 번역 후 [humanizer-korean-tech](../../humanizer-korean-tech/SKILL.md)를 전체 읽고 기본 모드를 적용한다.
- 원문 추적표에서 각 번역 블록을 원문 블록에 일대일로 연결한다.

### 압축 정리

- 고유한 주장·결론·예시·코드·figure·표·Red Flag를 유지한다.
- 반복 설명과 결론을 바꾸지 않는 사족을 삭제하거나 합칠 수 있다.
- 압축본을 만든 뒤 [humanizer-korean-tech](../../humanizer-korean-tech/SKILL.md)를 전체 읽고 강한 모드를 적용한다.
- 원문 추적표에 유지·통합·삭제한 원문 블록과 이유를 모두 기록한다.

### 핵심 요약

- 장의 중심 주장, 절별 결론, Red Flag와 이를 이해하는 데 필요한 예시·코드·figure를 유지한다.
- 부차적 사례와 세부 설명을 생략할 수 있다.
- 요약본을 만든 뒤 [humanizer-korean-tech](../../humanizer-korean-tech/SKILL.md)를 전체 읽고 강한 모드를 적용한다.
- 원문 추적표에 유지·통합·삭제한 원문 블록과 이유를 모두 기록한다.

모든 결과 문장과 MDX 요소를 원본 PDF의 한 블록 이상에 연결한다. 이 원문 추적성이 결과 내용의 경계다.

## MDX 모드

### 원본 대응

- 원본 heading, 강조, 목록, 표, 코드, 이미지와 의미 박스를 같은 종류의 Markdown·MDX 구조로 복원한다.
- 모든 강조·Callout·표를 PDF의 대응 구조에 연결한다.

### 의미 MDX

- 원본 대응 규칙을 모두 적용한다.
- 원문이 명시적으로 핵심 정의·경고·결론으로 표시한 문장은 표현 카탈로그가 정한 bold 또는 `Callout`으로 나타낼 수 있다.
- 추가 표현은 카탈로그에 등록한 bold와 `Callout`으로 제한하고, 강조 범위에는 원문 문구만 사용한다.

### 학습형 MDX

- `압축 정리` 또는 `핵심 요약`과만 조합한다.
- 원문에 명시된 비교·대응 관계를 표로 재구성할 수 있다.
- 표의 모든 셀을 원문 추적표의 원문 블록에 연결한다.
- 분류, 평가와 우선순위는 원문이 명시한 관계만 사용한다.

## 공통 표현 규칙

- frontmatter `title`은 `Chapter`·`Part` 라벨과 번호를 포함한 인쇄된 전체 heading을 사용한다.
- frontmatter `description`은 원문 보존에서 heading 뒤 첫 번째 완전한 문장을 그대로 사용하고, 완전 번역에서는 그 문장을 빠짐없이 번역한다. 압축 정리·핵심 요약에서는 원문 블록에 연결되는 표현을 사용한다.
- prose 문장 순서를 유지하고 떠 있는 figure·표·의미 박스만 설명하는 절의 첫 관련 문단 뒤로 옮길 수 있다.
- 모든 MDX 모드에서 챕터 본문의 코드, 식별자, 명령어와 코드 리터럴은 인라인 코드로 표시할 수 있다. 목차와 색인은 원문 표기를 유지한다.
- 코드 이미지는 PDF 렌더를 기준으로 copyable fenced code로 전사하고 원문 캡션을 바로 뒤에 둔다.
- 수식은 프로젝트의 fenced `math`와 인라인 수식 문법을 사용한다.
- 책의 특별한 개념과 구조화된 설명 방식에는 책별 표현 카탈로그의 표준 MDX 표현을 사용한다.
- 의미상 변화가 생길 수 있는 판단은 원문 표현을 유지한다.
